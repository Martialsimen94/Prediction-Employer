# Frontend

React 19 + TypeScript + Vite + Tailwind CSS v4 SPA for the AI Employee
Retention Platform. See the repo root [README](../README.md#frontend) for
what this app does and how it fits with the rest of the platform.

```bash
cp .env.example .env    # point VITE_API_BASE_URL at the running backend
pnpm install
pnpm dev                 # http://localhost:5173
pnpm test
pnpm build
pnpm lint
pnpm format:check
```
